Truyện phổ biến

Quy trình 5 bước

Các bước đã thực hiện để xây dựng trang web này, theo đúng thứ tự.

Bước 01

Khởi tạo và kết nối Repository

Tạo local repository, tạo repo Public trên GitHub rồi kết nối hai bên.

git init git remote add origin https://github.com/hanashiro-desu/ThucHanhGit_1822031202
Bước 02

Commit cơ bản

Đưa README.md và index.html vào staging area, sau đó commit đầu tiên.

git add . git commit -m "Thêm README và cấu trúc HTML"
Bước 03

Làm việc với nhánh

Tạo nhánh tính năng, thêm style.css rồi đẩy nhánh lên GitHub.

git checkout -b feature/them-giao-dien git push -u origin feature/them-giao-dien
Bước 04

Gộp nhánh (Merge)

Quay về main, gộp nhánh tính năng và đẩy bản mới nhất lên GitHub.

git checkout main git merge --no-ff feature/them-giao-dien git push origin main
Bước 05

Nhánh bổ sung: JavaScript

Main giữ index.html và style.css. Nhánh riêng chứa app.js để trang có chức năng đọc truyện, rồi gộp vào main.

git checkout -b feature/them-javascript git merge --no-ff feature/them-javascript

Các lệnh Git đã dùng

Tóm tắt nhanh mục đích của từng lệnh.

🚀

git init

Khởi tạo local repository trong thư mục hiện tại.

🔗

git remote add

Kết nối local repo với repo trên GitHub.

📥

git add

Đưa file vào vùng chờ staging để chuẩn bị commit.

💾

git commit

Lưu snapshot các thay đổi vào lịch sử với thông điệp.

🌿

git checkout -b

Tạo nhánh mới và chuyển sang nhánh đó.

🔀

git merge

Gộp thay đổi từ nhánh khác vào nhánh hiện tại.

☁️

git push

Đẩy commit từ máy local lên GitHub.

📜

git log

Xem lịch sử commit và cây nhánh.
